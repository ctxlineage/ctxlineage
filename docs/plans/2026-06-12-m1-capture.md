# M1 — Capture Core Implementation Plan

> **For Claude:** Execute task-by-task, in order. Every task ends with the full test suite passing and a commit. TDD: write the failing test first, watch it fail, implement, watch it pass. Tracking issue: #1.

**Goal:** `ctxlineage.init()` monkey-patches the openai SDK so every Chat Completions / Responses API call (sync, async, streaming) is appended as a schema-valid JSON line to `.ctxlineage/events.jsonl`.

**Architecture:** Three small modules behind one public function. `_events.py` owns event construction + the append-only JSONL writer; `_stack.py` summarizes the user call stack; `_instrument/openai_patch.py` wraps SDK methods with `wrapt` and proxies streams to assemble chunks. Module-level state (`_state.py`) holds the writer + session id. Capture must never break the host app: every recording path is wrapped in best-effort error suppression.

**Tech Stack:** Python 3.10+, `wrapt` (only runtime dep), `hatchling` + `uv`, `pytest` + `pytest-asyncio` + `respx` (mocked httpx transport — the openai SDK is httpx-based) + `jsonschema` (dev only).

**Out of scope (YAGNI, later milestones):** anthropic SDK (M4), span/tag API (M3), report CLI (M2), `tiktoken` (M2 — M1 records the provider's real `usage` only), redaction (M4).

---

## Design decisions

- **Event envelope (schema v1):** `{schema_version: 1, event_type, session_id, span_id, call_id, timestamp, payload}`. `event_type` enum is `llm_call | tag | span_start | span_end` — all four reserved now so the schema is stable, but M1 only emits `llm_call`. Unknown/extra data always goes inside `payload` (additionalProperties: true), never the envelope (additionalProperties: false).
- **`llm_call` payload:** `provider, api, request (all kwargs as passed), response, usage, stream, duration_ms, call_stack, error?`. Request kwargs are stored wholesale — unknown SDK fields pass through by design (PLAN.md §12).
- **Session = process:** one `session_id` (uuid4 hex) minted at `init()`. `call_id` minted per LLM call. `span_id` stays `null` until M3.
- **Writer:** open-append-close per event under a `threading.Lock`. No buffering, no daemon thread. `json.dumps(..., ensure_ascii=False, default=str)` so non-JSON types degrade to strings instead of raising.
- **Storage dir resolution:** `init(directory)` arg → `CTXLINEAGE_DIR` env var → `./.ctxlineage`.
- **Idempotency:** `init()` twice is safe; SDK patching happens at most once per process. A test-only `_reset()` clears state but cannot unpatch (wrapt patches are permanent — tests must tolerate patched-but-unconfigured SDK, which is also the "user forgot init()" production case: wrappers no-op when state is unconfigured).
- **Streaming:** wrap the returned `Stream`/`AsyncStream` in a `wrapt.ObjectProxy` that tees chunks during iteration and records ONE `llm_call` event when iteration finishes (or the context manager exits). Assembled output: concatenated `choices[*].delta.content` per index + last non-null `usage` seen (covers `stream_options={"include_usage": True}`).

## Task 3: Event construction + JSONL writer

**Files:** Create `src/ctxlineage/_events.py`, `tests/test_events.py`.

```python
from __future__ import annotations

import json
import threading
import uuid
from datetime import datetime, timezone
from pathlib import Path

SCHEMA_VERSION = 1


def new_id() -> str:
    return uuid.uuid4().hex


def utc_now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


def make_event(event_type, session_id, payload, *, span_id=None, call_id=None):
    return {
        "schema_version": SCHEMA_VERSION,
        "event_type": event_type,
        "session_id": session_id,
        "span_id": span_id,
        "call_id": call_id,
        "timestamp": utc_now_iso(),
        "payload": payload,
    }


class EventWriter:
    """Append-only JSONL writer. One event per line, no buffering."""

    def __init__(self, directory):
        self._dir = Path(directory)
        self.path = self._dir / "events.jsonl"
        self._lock = threading.Lock()

    def write(self, event: dict) -> None:
        line = json.dumps(event, ensure_ascii=False, default=str)
        with self._lock:
            self._dir.mkdir(parents=True, exist_ok=True)
            with self.path.open("a", encoding="utf-8") as f:
                f.write(line + "\n")
```

**Tests:** writer creates dir; two writes append two parseable lines; `make_event` output passes `validate_event`; non-JSON value (e.g. a `datetime`) in payload does not raise.

`openai_patch.py` core:

```python
import time
import wrapt

from ctxlineage import _state
from ctxlineage._stack import stack_summary

_PATCHED = False


def install() -> bool:
    global _PATCHED
    if _PATCHED:
        return True
    try:
        import openai  # noqa: F401
    except ImportError:
        return False
    wrapt.wrap_function_wrapper(
        "openai.resources.chat.completions", "Completions.create", _make_wrapper("chat.completions")
    )
    wrapt.wrap_function_wrapper(
        "openai.resources.chat.completions", "AsyncCompletions.create", _make_async_wrapper("chat.completions")
    )
    _PATCHED = True
    return True


def _base_payload(api, kwargs):
    return {
        "provider": "openai",
        "api": api,
        "request": dict(kwargs),
        "stream": bool(kwargs.get("stream")),
        "call_stack": stack_summary(),
    }


def _dump(response):
    try:
        return response.model_dump(mode="json")
    except Exception:
        return str(response)


def _make_wrapper(api):
    def wrapper(wrapped, instance, args, kwargs):
        if not _state.is_configured():
            return wrapped(*args, **kwargs)
        payload = _base_payload(api, kwargs)
        start = time.monotonic()
        try:
            result = wrapped(*args, **kwargs)
        except Exception as exc:
            payload["duration_ms"] = (time.monotonic() - start) * 1000
            payload["error"] = {"type": type(exc).__name__, "message": str(exc)}
            _state.emit("llm_call", payload, call_id=_events.new_id())
            raise
        payload["duration_ms"] = (time.monotonic() - start) * 1000
        if payload["stream"]:
            return _StreamProxy(result, payload)   # Task 7
        data = _dump(result)
        payload["response"] = data
        payload["usage"] = data.get("usage") if isinstance(data, dict) else None
        _state.emit("llm_call", payload, call_id=_events.new_id())
        return result
    return wrapper
```

## Task 7: Sync streaming

**Files:** Modify `openai_patch.py` (add `_StreamProxy`, `_assemble_chat`), extend `tests/test_openai_chat.py`.

```python
class _StreamProxy(wrapt.ObjectProxy):
    def __init__(self, wrapped, payload):
        super().__init__(wrapped)
        self._self_payload = payload
        self._self_chunks = []
        self._self_done = False

    def _self_finish(self):
        if self._self_done:
            return
        self._self_done = True
        p = self._self_payload
        p["response"] = _assemble_chat(self._self_chunks)
        p["usage"] = p["response"].get("usage")
        _state.emit("llm_call", p, call_id=_events.new_id())

    def __iter__(self):
        try:
            for chunk in self.__wrapped__:
                self._self_chunks.append(_dump(chunk))
                yield chunk
        finally:
            self._self_finish()

    def __enter__(self):
        self.__wrapped__.__enter__()
        return self

    def __exit__(self, *exc):
        try:
            return self.__wrapped__.__exit__(*exc)
        finally:
            self._self_finish()
```

`_assemble_chat(chunks)`: returns `{"object": "chat.completion.assembled", "content": {index: concatenated delta.content}, "finish_reasons": {...}, "usage": <last non-null>, "chunk_count": n, "model": ..., "id": ...}`.

**respx SSE mock:** `httpx.Response(200, headers={"content-type": "text/event-stream"}, content=b"data: {...}\n\ndata: {...}\n\ndata: [DONE]\n\n")` with 2 content chunks + a final usage chunk.

**Tests:** iterating fully → one event, assembled content equals concatenation, `stream: true`, usage captured; abandoning mid-iteration then `close()`/`__exit__` → still exactly one event.
